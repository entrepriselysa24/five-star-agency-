# Five Star Agency · fivestaragency.it

Sito di Five Star Agency: marketing, social media, branding e web con il Metodo 5S.

## Struttura

```
index.html        la pagina (testi e sezioni)
src/main.js       animazione 3D (Three.js) e link WhatsApp dei pacchetti
src/style.css     grafica nero e oro
public/           file pubblici (favicon)
package.json      dipendenze: three, vite
```

`node_modules` e `dist` non si caricano: li crea Vercel da solo con `npm install` e `npm run build`.

## Vercel

Framework Preset: **Vite** · Build Command: `npm run build` · Output Directory: `dist`

## Sul computer (facoltativo)

```
npm install
npm run dev
```
